## Решения

- 2026-10-13: пользователь выбрал «Экран Windows» и в Mac-приложении, и в браузерной панели. Это текущий рабочий стол, включая обычный Chrome с его профилем; CDP использует отдельный профиль. Источник — решения в сессии, проверка тестового Windows-окна; подробности и статус доставки: [browser.md](browser.md).
- 2026-10-13: Ctrl+Cmd+Enter и синяя кнопка рядом с Capture Input включают desktop fullscreen на выбранном дисплее; повторный аккорд выходит. Захват начинается после первого кадра. Источник — запрос пользователя, `app.rs`, тесты и живая проверка кнопки; физический аккорд пока не проверен.
- 2026-10-13: браузер и desktop должны сохранять параллельные exec и PTY. Источник — требование пользователя и живая нагрузочная проверка; замеры в [browser.md](browser.md).
- 2026-10-13: пользователь отказался от копирования хоста в Program Files и выбрал ручной запуск прямо из `C:\Download\prjcts\wiredesk\target\release\wiredesk-host.exe`. Источник — уточнение пользователя и read-only проверка пути процесса/хэша через WireDesk после сборки `9839d5e`; процедура — [run.md](run.md).

## Ловушки

- 2026-10-13: синтетическое нажатие в native UI-инструменте не доказывает работу CGEventTap; AX-клик по изображению не равен физическому вводу мыши. Проверять физический ввод отдельно. Источник — UI-проверка сессии.
- 2026-10-13: sandbox даёт ложные падения IPC/NSPasteboard, генерации icns и проверки доверия локальному сертификату. Сверять конкретную ошибку и повторять нужную проверку с доступом к системному ресурсу; не менять код по одному такому падению. Источник — повторные успешные проверки той же сборки.
- 2026-10-13: отчёт независимого ревью дважды предположил ошибку rustfmt, но фактический `cargo fmt --check` прошёл; утверждения ревью о формате и раскладке клавиш сверять с командами и `keymap.rs`. Источник — два прохода ревью и тест освобождения Windows Ctrl.
- 2026-10-13: вставленные по отдельности PowerShell-команды продолжили выполняться после ошибки, включая ложное сообщение об успехе. Давать установку/обновление единым `& { ... }` с проверками до остановки процесса; откат допустим только при существующей резервной копии, успех — после проверки запущенного процесса. Источник — ошибка старого скрипта в логе пользователя; для выбранного запуска из репозитория копирование exe больше не требуется.
